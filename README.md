# Warband HQ – Landing Page

The official landing page for **Warband HQ**, a World of Warcraft companion web application designed to bring your characters, progression and personal objectives together in one place.

## About the Project

Warband HQ started as a personal Google Sheets project connected to the Blizzard API. It gradually evolved into a web application with the goal of providing World of Warcraft players with a central place to manage their entire warband.

This repository contains the public landing page introducing the project, its story and its main features.

## Features

- **Project Presentation** – Discover Warband HQ and its goals.
- **Character Management** – Get an overview of your World of Warcraft characters.
- **Progression Tracking** – Review character information and follow their journey.
- **Personal Goals** – Organize objectives, tasks and priorities.
- **English & French** – Switch between English and French.
- **Responsive Design** – Designed for desktop and mobile screens.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- WebP images and SVG icons

No frontend framework or build tool is required.

## Getting Started

### Run Locally

Clone the repository:

```bash
git clone https://github.com/Crypoune/warband_hq_landing_page.git
```

Open the project folder:

```bash
cd warband_hq_landing_page
```

Launch the `index.html` file in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
